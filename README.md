## ✨ Fitur Unggulan

- [x] **Katalog Produk Dinamis:** Menampilkan berbagai jenis kaktus & sukulen lengkap dengan harga dan deskripsi.
- [x] **Dual Action Button:** Tombol *Tambah ke Keranjang* dan *Beli Sekarang* (Direct Checkout) untuk kemudahan bertransaksi.
- [x] **Respon Desain Adaptif:** Tampilan modern dan rapi berbasis Tailwind CSS (Flexbox & Grid layout).
- [x] **Sistem Checkout Terintegrasi:** Proses pemesanan aman dan otomatis mengelola data pesanan user.
- [x] **Footer Kondisional:** Tampilan promosi khusus yang responsif hanya pada halaman utama.
- [x] **Live Cloud Deployment:** Sudah siap diakses secara publik via Railway Cloud Infrastructure.

## 🛠️ Teknologi yang Digunakan

- **Backend:** Laravel 10/11, PHP 8.x
- **Frontend:** Blade Templating, Tailwind CSS, JavaScript
- **Database:** MySQL
- **Deployment:** Railway Engine
